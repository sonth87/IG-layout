# Checklist thử trên thiết bị thật (trước v1.0)

> Những mục này **không tự động hoá được** — cần chủ dự án thử trên điện thoại thật với https://ig-layout.vercel.app/.
> Ghi kết quả (✓ / ✗ + ghi chú, loại máy, phiên bản iOS / Android) vào cột "Kết quả".

| # | Việc cần thử | iPhone (Safari) | Android (Chrome) |
|---|---|---|---|
| 1 | Cài app lên màn hình chính; mở lại từ biểu tượng | | |
| 2 | Bật chế độ máy bay → mở app → vẫn dùng được | | |
| 3 | Tạo Post, chọn **20 ảnh thật** từ thư viện (có ảnh HEIC trên iPhone) — thời gian nhập, có ảnh nào lỗi không | | |
| 4 | Kéo, chụm / xoay hai ngón một ảnh — có mượt, có nhầm với cuộn dải slide không | | |
| 5 | Vuốt vùng trống để cuộn dải slide | | |
| 6 | Chỉnh màu / filter — kéo slider có mượt không | | |
| 7 | Chữ tiếng Việt: gõ bằng bàn phím điện thoại, font hiển thị đúng dấu | | |
| 8 | Xuất → **Lưu vào Ảnh** — ảnh có vào thư viện, đúng thứ tự, đúng kích thước | | |
| 9 | Đăng thử carousel lên Instagram — vuốt có liền mạch, có bị cắt | | |
| 10 | Đăng thử 1 Story có chữ gần mép — **vùng tô màu có khớp với phần bị che** (đang dùng 250 / 340 px) | | |
| 11 | Đăng thử Grid 3 × 1 (3 bài) — ảnh ghép trên trang cá nhân có khớp; **khe 12 px có đúng** | | |
| 12 | Đóng app giữa chừng, mở lại sau 1 ngày — project còn, hoàn tác được | | |
| 13 | Theme sáng / tối, tiếng Việt / tiếng Anh | | |
